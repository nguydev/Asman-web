## UX & Forms
- Never use hardcoded default values (e.g., "USA", "North America") in UI form states for unselected dropdowns or fields. 
- Always use empty strings (`''`) or `null` for unselected fields and provide a blank placeholder option (e.g., `<option value="">Select a region...</option>`). This prevents accidentally overwriting missing data with fake default values when saving forms.
- When replacing mock data with real API data, carefully verify image/photo properties against the backend DTO (e.g. `avatarUrl` instead of `photo`) and always ensure safe fallbacks (like initials) are used for missing image fields to prevent broken UI icons.
